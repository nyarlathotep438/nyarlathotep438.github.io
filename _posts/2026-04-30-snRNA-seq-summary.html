2026年04月30日 研究日志¶

今日主题：汇总数据集GSE135133的样本类别并绘制统计图表。数据集中所有样本均来自美国佛罗里达州 Tampa 的 Florida Lions Eye Bank，包含5位没有视网膜疾病的捐献者的视网膜单核RNA测序数据。

供体眼球在死亡后 5 小时内被摘除并立即在液氮中快速冷冻。研究者从眼球的视神经基部开始，以垂直于视神经的方向进行 60 μm 厚度的冷冻切片。切片中凡是能看到 RPE（视网膜色素上皮）层的后部区域，按每 8 张为一组收集用于单核 RNA 测序（下图中的区域1与区域2的划分）。

  • GSE135092：单核测序（snRNA-seq）数据集。样本来源于5位人类捐献者的视网膜，最终得到了11个有效样本用于单核测序研究，最终得到了121779个细胞的测序数据。捐献者与样本的关系见下表：

cols_to_plot <- c("sampleID", "Tissue", "Sex", "Cell_type_full")

# 循环绘图
for (col in cols_to_plot) {
  p <- clusters %>%
    count(.data[[col]]) %>% 
    ggplot(aes(x = .data[[col]], y = n, fill = .data[[col]])) +
    geom_col() +
    geom_text(aes(label = n), vjust = -0.3) +
    theme_bw() +
    labs(
      title = paste("Frequency of", col),
      x = col,
      y = "Count"
    ) +
    theme(legend.position = "none")
  
  print(p)
}
