Biohub - Cell Tracking During Development（ https://www.kaggle.com/competitions/biohub-cell-tracking-during-development ）¶

这个竞赛所要解决的问题是 → 在延时三维成像显微镜图像中追踪细胞。注意本次比赛使用的成像对象是斑马鱼的胚胎，是活体，所以它有着全部的生物的生理学过程，这对解决这一问题有着明确的影响
这个问题的难点在于以下几点：

  1. 显微镜图像的对比度，明暗等像素层面的变化绝不仅仅来源于细胞本身的生理学变化，而是更多地来自于仪器自身的调节，因此仪器噪声必须被考虑。另外，显微镜本身的成像特点也会影响结果，比如Z轴的分辨率明显不如X轴和Y轴，这是物理性质决定的，没有什么很好的解决办法。
  2. 显微镜下的细胞实际上特征并不足够显著，同时也经常发生变化，这也是大量自动化工具难以获得良好效果的原因。实际上即使对于人类，也需要经过一段时间的训练，再加上耗费大量时间的反复比对才能找到相对应的细胞。
  3. 最特别的是，活体细胞不仅仅会随着时间的推进而移动，其本身就会变形和分裂。实际上，本次竞赛使用的是活体斑马鱼胚胎细胞。胚胎细胞为了生长有着夸张的活动效率。也就是说，我们面对的是最会移动，变形和分裂的一类细胞。

import zarr
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

zarr_path = r"C:\PhD Project\Kaggle\biohub-cell-tracking-during-development\train\6bba_0c7fa718.zarr"
geff_path = r"C:\PhD Project\Kaggle\biohub-cell-tracking-during-development\train\6bba_0c7fa718.geff"

zarr_root = zarr.open(zarr_path, mode="r")
img = zarr_root["0"][:]   

geff_root = zarr.open(geff_path, mode="r")

node_ids = geff_root["nodes/ids"][:]
t_vals = geff_root["nodes/props/t/values"][:]
z_vals = geff_root["nodes/props/z/values"][:]
y_vals = geff_root["nodes/props/y/values"][:]
x_vals = geff_root["nodes/props/x/values"][:]

nodes_df = pd.DataFrame({
    "node_id": node_ids,
    "t": t_vals,
    "z": z_vals,
    "y": y_vals,
    "x": x_vals,
})

t_show = 0
z_show = 44

nodes_slice = nodes_df[(nodes_df["t"] == t_show) & (nodes_df["z"] == z_show)]

plt.figure(figsize=(8, 8))

plt.imshow(img[t_show, z_show], cmap="gray")

# geff point + node_id
for _, row in nodes_slice.iterrows():
    x, y = row["x"], row["y"]
    node_id = row["node_id"]

    # red point
    plt.scatter([x], [y], s=40, edgecolors="red", facecolors="none", linewidths=1.5)

    # node_id
    plt.text(x + 3, y + 3, str(node_id),
             color="yellow", fontsize=8, weight="bold")
    
plt.title(f"t={t_show}, z={z_show}, nodes={len(nodes_slice)}")
plt.show()
